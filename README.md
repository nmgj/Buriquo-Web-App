# Buriquo Web App

This repository contains a sample static website project that is ready to deploy on GitHub Pages.

## Deploy on GitHub Pages

1. Commit and push this repository to GitHub.
2. Open the repository settings on GitHub.
3. In the **Pages** section, choose one of these options:
   - Set the source to the `main` branch and use the root folder (`/`).
   - Or set the source to the `gh-pages` branch if you want to use the provided workflow.
4. Save the settings.
5. Your site will be published at `https://<your-username>.github.io/<repository-name>/`.

## Files included

- `index.html` - the website homepage
- `styles.css` - page styling
- `script.js` - page behavior

## Customize

Edit the HTML, CSS, and JavaScript files to add your own content, branding, and features.
